How to Add a New Host as a Niki Live Agent

Building a successful agency starts with recruiting and supporting talented hosts.

1

Step 1: Open the Agency Menu

Go to your Niki Live profile and select the “Agency” menu.

2

Step 2: Select Add Host

Click the “Add Host” button to begin the host invitation process.

3

Step 3: Enter Host ID

Input the Niki ID of the host you want to invite.

4

Step 4: Confirm Host Information

After the correct host profile appears, review the information and click “Add”.

5

Step 5: Host Receives Invitation

The invited host will receive an invitation notification through their Niki Live application.

6

Step 6: Host Accepts Invitation

The host must accept the invitation and complete the required verification process, including face and ID verification (if required).

7

Step 7: Host Joins Your Agency

After confirmation, the host will officially become part of your Niki Live agency and can begin livestreaming under your management.

How to Add a New Sub-agent as a Niki Live Agent

Expand your agency network by inviting qualified sub-agents. Sub-agents can operate independently while contributing to your overall agency growth.

1

Step 1: Open Agency Menu

Go to your Niki Live profile and select the “Agency” menu.

2

Step 2: Select Invite Sub-agent

Click the “Invite Sub-Agent” option to generate an invitation.

3

Step 3: Share Invitation Link

Copy the sub-agent invitation link and send it to the person you want to invite.

4

Step 4: Guide the New Sub-agent

Ask the invited sub-agent to complete the following steps:

  1. Open Profile Section: Access their Niki Live profile and select “Copy ID”.
  2. Submit Their Niki ID: Enter the ID and click “Send”.
  3. Receive Verification Code: The verification code will be sent through the Niki Live account message system.
  4. Complete Verification: Copy the verification code and click “Submit”.
